# 배경음 넣는 곳

음원 파일(`.mp3` `.wav` `.m4a` `.flac` `.ogg`)을 **하나** 넣고 다시 빌드하면
합성 대신 그 음악이 깔린다. 길이에 맞춰 반복·자르고 앞뒤 페이드까지 자동이다.

**비워 두는 것이 기본이다.** `pipeline/audio.py` 가 구간별로 직접 친다.
직접 치는 쪽이 나은 이유는 하나다 — **특정 순간에 음악을 끊을 수 있다.**
"그런데" 로 뒤집히는 장면에서 음악이 뚝 끊기는 것은 고정 음원으로 할 수 없다.

## "클래식이니까 무료"는 함정이다

**곡**과 **녹음**의 권리가 따로다.

- 바흐·쇼팽·사티의 **악보**는 공유재산이다
- 그런데 **누군가 연주한 녹음**에는 그 연주자·음반사의 권리가 살아 있다 (보통 발매 후 70년)

유튜브에서 받은 "쇼팽 녹턴"을 쓰면 걸린다. 걸리는 건 쇼팽이 아니라 그 연주다.

사운드클라우드의 "Free Download"도 *내려받아도 된다*는 뜻이지
*영상에 써도 된다*는 뜻이 아니다.

## 안전한 곳

| 출처 | 조건 |
| --- | --- |
| **Musopen** (musopen.org) | 공유재산 클래식 **녹음**. 이 용도에 가장 적합 |
| **YouTube 오디오 보관함** | 전용 제작 음원. 일부 저작자 표시 |
| **Pixabay Music** | 조건 없음 |
| **Free Music Archive** | CC 라이선스. 곡마다 다르니 CC0/CC-BY 확인 |
| **Incompetech** | CC-BY — 저작자 표시 필요 |

Wikimedia Commons 에도 CC0 녹음이 있다. 파일 페이지의 라이선스 필드를 직접 확인한다.

## 고를 때

다큐 나레이션 밑에 깔 음악은 **사건이 적어야** 한다. 선율이 뚜렷하면 말과 싸운다.
느리고 단조로운 것을 고른다. 좋은 음악일수록 나레이션을 잡아먹는다.

## 저작자 표시가 필요하면

마지막 카드나 설명란에 한 줄 넣는다.

```
음악: <곡명> — <연주자> (<출처>, <라이선스>)
```
